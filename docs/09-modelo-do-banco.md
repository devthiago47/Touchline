# Touchline

# Modelo do Banco de Dados

## Objetivo

Definir as principais entidades do banco de dados.

---

## Entidades

- Liga
- Clube
- Jogador
- Competição
- Partida
- Temporada
- Save

---

## Relacionamentos

Uma Liga possui vários Clubes.

Um Clube possui vários Jogadores.

Uma Competição possui várias Partidas.

Um Save possui uma Temporada ativa.

---

## Observação

Os detalhes das tabelas serão definidos durante a implementação utilizando Prisma.
